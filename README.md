# Business Automation Agents

Reusable, end-to-end Codex skills for turning real business bottlenecks into reliable systems. These are not generic prompt collections. Each skill is designed to start with a workflow, preserve an accountable human decision where needed, and leave behind a measurable operating result.

## What this covers

| Skill | Business outcome |
| --- | --- |
| `workflow-automation-discovery` | Finds the highest-value process to automate before building |
| `lead-to-quote-automation` | Turns enquiries into qualified opportunities and approved quotes |
| `customer-operations-copilot` | Routes support work and protects service quality |
| `document-intelligence-ops` | Converts incoming documents into reviewed, structured work |
| `internal-knowledge-agent` | Provides sourced answers from permitted company knowledge |
| `executive-operations-brief` | Produces a decision-ready daily operations brief |

## Principles

- Build around an observable business workflow, not a fashionable framework.
- Make data sources, permissions, and owners explicit.
- Draft and recommend freely; require approval for customer communications, payments, system writes, access changes, or irreversible actions.
- Measure the result: response time, lead conversion, backlog age, rework, time saved, or error rate.
- Ship a maintainable system with a clear stop condition and recovery path.

## Use

Copy a skill folder into a Codex-compatible skills directory or keep it in a project under `.codex/skills`. Invoke the skill by name, for example: `Use $lead-to-quote-automation to design our enquiry-to-proposal workflow.`

## Who this is for

Business owners, operations teams, agencies, service businesses, e-commerce teams, property and field-service operators, and growing companies that need their systems to work together.
